# 睡够就叫我

从「真正睡着的那一刻」开始计时的闹钟。睡前点一下开始守夜，放下手机，睡够你设的时长才响。

假期、倒班、作息不规律时最合适：没有固定起床时间，只有一个「睡够」的目标。

## 功能

- **判定入睡**：熄屏 + 持续静止 8 分钟才算睡着（刷手机时屏幕是亮的，不会误判）
- **从入睡起算**：睡满设定时长才响，不是从躺下算，也不是从现在算
- **系统闹钟**：走 setAlarmClock，Doze 和省电策略也挡不住
- **响得够狠**：全屏弹出 + 最大音量 + 循环震动，长按 3 秒才关得掉，也可以「再睡 9 分钟」
- **记潜伏期**：显示你躺下后多久才睡着，攒几晚就知道自己该几点上床

## 下载安装

1. 打开仓库 **Actions** → 最近一次成功的 `build-apk`
2. 页面底部 **Artifacts** → 下载 `sleepafter-debug.zip`，解压得到 `app-debug.apk`
3. 传到手机安装（允许「未知来源」）
4. 升级时直接覆盖安装，设置和记录都保留

## 首次设置

四项，缺一项都可能不响：

1. 允许**通知**
2. **精确闹钟权限** → 系统里打开「闹钟和提醒」
3. **电池白名单** → 允许忽略电池优化
4. 国产 ROM 额外设置：应用管理 → 睡够就叫我 → **自启动**打开、**省电策略**改「无限制」、**允许后台弹出界面**

## 使用

1. 睡前把手机**插上充电**，放在床上（枕头边）
2. 点大数字设置时长（小时 + 分钟，5 分钟一档）
3. 点「开始守夜」，进入守夜页，看倒计时
4. 放下手机睡觉，到点响了长按 3 秒关闭

## 判定规则

- 只有「屏幕熄灭 + 持续静止」才计时，亮屏即刻清零
- 静止时长可调：点「判定入睡」在 5 / 8 / 12 / 15 / 20 分钟之间切换
- 最多守夜 3 小时，超时静默放弃，不会半夜乱响
- 深睡翻身会重置计时，所以判定时刻通常略晚于真实入睡——宁可晚判，也不会早响

## 常见问题

| 现象 | 处理 |
|---|---|
| 整夜没反应 | 检查电池白名单和自启动，国产 ROM 是主要原因 |
| 手表不震 | 小米运动健康里打开通知同步；手机闹钟本身照响，不影响起床 |
| 想更灵敏 | `SleepWatchService.kt` 里 `STILL_SD` 从 `0.035` 调到 `0.05` |
| 响得太早或太晚 | 先看守夜页显示的判定时刻，判断是判早了还是判晚了 |

## 自己编译

需要 JDK 17 + Android SDK 34：

```bash
gradle assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 代码结构

```
app/src/main/java/com/dafeiyu/sleepafter/
├── MainActivity.kt        主界面、时长选择、权限引导
├── WatchActivity.kt       守夜页（倒计时）
├── SleepWatchService.kt   核心：加速度判定入睡
├── AlarmScheduler.kt      系统闹钟封装
├── AlarmReceiver.kt       到点触发全屏
├── RingActivity.kt        响铃界面
├── BootReceiver.kt        重启后恢复闹钟
└── Store.kt               状态持久化
```
